# social-media-midia

Repositório **público**, só com as imagens dos posts do @edsonoliveiraoficial. Ele serve para entregar ao Metricool um link direto de cada arte.

- A fonte oficial (estratégia, fila, relatórios) é o repositório privado `altovalorcode/Social-Media`. Este aqui é só um espelho de `midia/`.
- Estrutura: `AAAA-MM/<id>/<id>_NN.png`, por exemplo `2026-10/AV91/AV91_01.png`.
- Link direto: `https://raw.githubusercontent.com/altovalorcode/social-media-midia/main/AAAA-MM/<id>/<id>_NN.png`
- Não coloque aqui nada além de imagens e vídeos de posts: nada de números, estratégia ou dados de clientes.
